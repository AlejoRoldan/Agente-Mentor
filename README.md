# Agente-Mentor
La mentoría aumentada no reemplaza mentores; institucionaliza memoria y criterio para que cada estudiante reciba acompañamiento consistente, incluso cuando el mentor humano no está disponible.
Por qué importa para IttiAcademy:
Escala acompañamiento sin contratar proporcionalmente más tutores.
Reduce abandono y “mesetas” (cuando el estudiante se estanca).
Hace que el curso sea un sistema adaptativo, no solo contenido.
Lo que cambia:
La mentoría deja de ser un evento y pasa a ser un continuo: cada sesión empieza donde terminó la anterior.
